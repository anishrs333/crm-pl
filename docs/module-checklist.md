# CRM Software - Module Feature Checklist

This document tracks the implementation progress for all core modules of the PL Soft Tech Solutions CRM Software.

---

## 1. Admin Dashboard
- [ ] Overview KPI cards (Total Leads, Active Deals, Revenue, Open Tasks)
- [ ] Sales conversion funnel chart
- [ ] Recent activities & audit log feed
- [ ] Quick action shortcuts (Create Lead, New Quotation, Add Task)
- [ ] Role-based dashboard widgets and access control

---

## 2. Lead Management
- [ ] Lead capture form & API endpoint
- [ ] Lead list view with status filters (New, Contacted, Qualified, Lost, Converted)
- [ ] Lead detail view with contact info and timeline
- [ ] Lead scoring and temperature indicator (Hot / Warm / Cold)
- [ ] Lead assignment and re-allocation to sales reps
- [ ] Lead conversion to Customer / Opportunity workflow
- [ ] CSV import / export for leads

---

## 3. Customer Management
- [ ] Customer / Account directory and profile management
- [ ] Contact persons management per company
- [ ] Customer interaction history & 360-degree view
- [ ] Customer classification & tags (Enterprise, SMB, VIP)
- [ ] Associated deals, quotations, and invoice history
- [ ] Document attachment storage per customer

---

## 4. Sales & Opportunity Management
- [ ] Visual Kanban board with drag-and-drop pipeline stages
- [ ] Opportunity value, expected close date, and win probability
- [ ] Pipeline stage customization (Discovery, Proposal, Negotiation, Won, Lost)
- [ ] Reason for loss tracking and analytics
- [ ] Revenue forecasting and quota progress tracking

---

## 5. Follow-up Management
- [ ] Scheduled follow-up reminders (Call, Email, Meeting)
- [ ] Follow-up calendar integration / timeline view
- [ ] Automated reminders via email / notification
- [ ] Follow-up logs and outcome notes recording
- [ ] Overdue follow-up alerts

---

## 6. Quotation Management
- [ ] Quotation builder with itemized product/service line items
- [ ] Dynamic tax, discount, shipping, and total calculation
- [ ] PDF export and template generation
- [ ] Quotation status workflow (Draft, Sent, Approved, Rejected, Expired)
- [ ] One-click conversion of Quotation to Sales Order / Invoice
- [ ] Email quotation directly to customer with tracking link

---

## 7. Product/Service Management
- [ ] Product catalogue with SKU, unit price, tax rate, and description
- [ ] Service offerings and billing models (Fixed, Hourly, Subscription)
- [ ] Category and tag classification
- [ ] Inventory / stock quantity tracking (if applicable)
- [ ] Price tier management and promotional discounts

---

## 8. Employee / User Management
- [ ] User authentication with JWT (Login, Token Refresh, Password Reset)
- [ ] Role-based access control (Admin, Sales Manager, Sales Rep, Support)
- [ ] User profile management and departmental teams
- [ ] Performance target and sales quota assignment
- [ ] Activity logs and security session auditing

---

## 9. Task Management
- [ ] Task creation with priority (Low, Medium, High, Urgent)
- [ ] Task assignment to users and link to Lead / Customer / Opportunity
- [ ] Due date alerts and recurring task automation
- [ ] Task list and Kanban status views (To-Do, In Progress, Completed)
- [ ] Sub-tasks and checklist support

---

## 10. Reports & Analytics
- [ ] Sales performance and rep leaderboard reports
- [ ] Lead generation source and conversion rate analysis
- [ ] Revenue analytics (Monthly Recurring Revenue, Closed Deals)
- [ ] Pipeline velocity and stage drop-off analysis
- [ ] Export reports to CSV / Excel / PDF
- [ ] Custom date-range filtering and scheduled report generation

---

## 11. Notifications
- [ ] Real-time in-app notification center
- [ ] Email notifications for assignment, due dates, and stage changes
- [ ] Notification preferences per user (Instant, Daily Digest, Mute)
- [ ] Unread counter and mark-as-read actions

---

## 12. Search & Filters
- [ ] Global search across Leads, Customers, Deals, and Quotations
- [ ] Advanced multi-criteria filters with saved filter presets
- [ ] Sorting and pagination across all tabular views
- [ ] Full-text search support for notes and descriptions
